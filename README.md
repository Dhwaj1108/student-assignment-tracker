# DueNote — Student Assignment Tracker

DueNote is a small assignment tracker made for a first-year web development project. Add classwork, keep an eye on deadlines, and mark tasks complete as you go.

## Features

- Add an assignment with a course, due date, and priority
- See what is due this week and track your completed work
- Filter by all, upcoming, or completed assignments
- Search by assignment or course and sort the list
- Save assignments in the browser with `localStorage`
- Use a responsive layout on desktop, tablet, and mobile
- Start with a few sample assignments, then remove them when you are ready

## Run it

No install or build step is needed.

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Add an assignment using the form.

Assignments are saved in the browser you use. They do not sync between devices.
